# Личный ИИ-помощник: Telegram + браузер

Первая версия объединяет Telegram-бота и адаптивное веб-приложение. Оба канала используют один список задач и одну переписку. Веб-приложение можно установить на главный экран телефона как PWA.

## Что уже реализовано

- Доска задач с колонками: «Не начато», «В работе», «Ждёт ответа», «На проверке», «Готово».
- Карточки с категорией, описанием, сроком и временем напоминания.
- Чат с ИИ через Azure OpenAI; модель может создать задачу, показать список и изменить её статус по явной просьбе.
- Telegram long polling. Пользователь задаётся через `TELEGRAM_OWNER_ID`; остальные аккаунты бот игнорирует.
- Напоминания в Telegram отправляются только для задач со статусом `new`, когда наступил срок напоминания. Для каждой карточки уведомление отправляется один раз. «Начал» переводит задачу в `active` и отключает напоминание о начале.
- Авторизация веб-приложения общим кодом `APP_ACCESS_TOKEN`.

## Запуск локально

1. Установи Python 3.12 или новее.
2. Открой папку проекта и создай виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

3. Активируй окружение, затем установи пакеты:

   ```bash
   pip install -r requirements.txt
   ```

4. Скопируй `.env.example` в `.env` и заполни значения. Для локального запуска переменные нужно экспортировать в терминале или настроить в конфигурации запуска IDE.
5. Создай Telegram-бота у `@BotFather`, узнай свой Telegram user ID и заполни `TELEGRAM_BOT_TOKEN` и `TELEGRAM_OWNER_ID`. Напиши боту `/start`.
6. В Azure создай ресурс Azure OpenAI или модель в Azure AI Foundry, выполни deployment модели и заполни endpoint, key и deployment name.
7. Запусти приложение:

   ```bash
   python app.py
   ```

8. Открой `http://localhost:8000` на компьютере. Для телефона сайт должен быть доступен по адресу сервера в той же сети или опубликован через HTTPS.

Если Azure OpenAI пока не настроен, доска продолжит работать, но ИИ-ответы будут сообщать, что модель не подключена.

## Размещение в Azure

Проект собран как один контейнер веб-приложения, содержащий API, Telegram-поллер, проверку напоминаний и веб-интерфейс. Для постоянной работы фоновым процессам требуется запущенный экземпляр и постоянное хранилище для файла SQLite.

1. Создай Azure Web App for Containers или Azure Container Apps и загрузи этот проект как контейнер.
2. Настрой переменные окружения из `.env.example` через Azure Portal; секреты не помещай в репозиторий.
3. Настрой постоянный каталог для базы и задай `APP_DB_PATH` на этот каталог. Без постоянного диска задачи могут потеряться после пересоздания контейнера. В Azure Web App for Containers каталог `/home` сохраняется между перезапусками только при включённой настройке приложения `WEBSITES_ENABLE_APP_SERVICE_STORAGE=true` (проверь её в Azure Portal → Environment variables).
4. Включи постоянную работу приложения (Always On / минимум одна реплика). На бесплатном плане фоновые процессы могут останавливаться вместе со спящим приложением.
5. Ограничь доступ к приложению длинным уникальным `APP_ACCESS_TOKEN`; включи HTTPS.
6. Проверь `/api/health`, создай тестовую задачу с напоминанием и убедись, что сообщение пришло в Telegram.

Azure может тарифицировать приложение, базу/диск и модель отдельно. Перед публикацией посмотри прогноз стоимости и установи бюджет/уведомление в Cost Management. Кредит Azure в $200 обычно действует 30 дней, это не ежемесячное начисление.

## Настройка напоминания

При создании задачи задай «Напомнить начать». Пока карточка имеет статус `new`, после указанного времени бот отправит уведомление в Telegram. Нажатие «Начал» меняет статус на `active`. В Telegram то же делают сообщения «начал #N» и «готово #N» (где N — номер карточки); они обрабатываются кодом, без участия ИИ. Время напоминания без часового пояса считается временем `APP_TIMEZONE`. Завершённые и начатые задачи повторно не напоминаются. Часовой пояс браузера используется при вводе даты; сервер сохраняет её в UTC.

## Ограничения этой версии

- Одна личная учётная запись; нескольким пользователям приложение не предназначено.
- Требуются собственные Telegram Bot Token, Azure OpenAI key и deployment.
- Telegram-бот использует long polling; запусти только один экземпляр приложения, иначе несколько поллеров будут конфликтовать.
- Фоновые напоминания отправляются в Telegram. Браузер показывает ту же доску, но web push ещё не настроен.
- Удаление задачи и прикрепление файлов пока не реализованы.
